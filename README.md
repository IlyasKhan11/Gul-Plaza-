# Gul Plaza - E-commerce Platform

## Repository Structure

This repository follows a branch-based development workflow:

- **`dev` branch**: Contains all development code and features
- **`main` branch**: Clean branch for releases and deployments

## Development

All development work happens in the `dev` branch. Please use `dev` for:
- New features
- Bug fixes  
- Updates
- Testing

## Deployment

The `main` branch is kept clean and minimal for stable deployments.

## Team Workflow

1. Clone the repository
2. Switch to `dev` branch: `git checkout dev`
3. Make your changes
4. Commit and push to `dev`
5. Create pull requests targeting `dev`

## Security

- Environment variables (`.env`) files are never committed
- Sensitive data is stored in environment variables
- Follow security best practices
